El presente proyecto consiste en el diseño y desarrollo de una base de datos para la gestión de un restaurante, 
utilizando MySQL. SQL es fundamental para la gestión y análisis de bases de datos relacionales, ya que permite almacenar, 
consultar, modificar y relacionar información de manera estructurada. En este proyecto se aplicaron estos principios mediante 
la creación de tablas, definición de claves primarias y foráneas, establecimiento de relaciones entre las diferentes entidades 
y carga de datos artificiales para simular la operación de un restaurante. 

Finalmente, se desarrollaron consultas SQL para obtener, relacionar y analizar la información almacenada, aplicando conceptos como JOIN, 
funciones de agregación, GROUP BY y ORDER BY, demostrando cómo los datos pueden convertirse en información útil para la generación 
de reportes y la toma de decisiones basada en datos.
